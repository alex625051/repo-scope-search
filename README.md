# Repo Scope Search

Плагин PyCharm для надёжного потокового поиска по содержимому **во всех непустых неархивных GitLab-репозиториях, доступных текущему аккаунту**, включая личные проекты, групповые проекты и проекты, доступные через членство в группе.

## Что реализовано

- GitLab.com и self-hosted GitLab.
- Personal Access Token; кнопка открывает предзаполненную страницу создания токена.
- Получение всех проектов через `GET /api/v4/projects` (все проекты, доступные аутентифицированному аккаунту) с пагинацией по 100.
- Приоритет проектов: владелец/создатель/личное пространство, Owner, Maintainer, Developer, Reporter, Guest.
- Два глобальных прохода: сначала default branch каждого репозитория; только после этого все остальные ветки.
- Потоковая выдача: строка появляется в таблице сразу после обнаружения.
- Текст, regexp, case-sensitive, многострочный режим (`MULTILINE` + `DOT_MATCHES_ALL`), неточный поиск по нормированной дистанции Левенштейна.
- Контекст сверху/снизу, ветка, SHA коммита, ссылка на коммит, файл в найденном коммите и файл в основной ветке.
- Bare-кэш репозиториев и инкрементальный `git fetch`, без checkout рабочих деревьев.
- Токен хранится через IntelliJ `PasswordSafe` и не записывается в URL remote или `.git/config`.
- Пропуск бинарных файлов и настраиваемый предел размера файла.
- Отмена через кнопку и штатный индикатор PyCharm.

## Требования

- PyCharm 2025.3 или новее.
- JDK 21 для сборки.
- Git в `PATH` машины, где работает backend IDE.
- Токен GitLab со scope `api` (он уже включает API и Git-over-HTTP; `read_repository` можно отметить дополнительно для явности). Плагин выполняет только операции чтения. Для организаций, принудительно использующих fine-grained PAT, выдайте эквивалентные read-разрешения Project/API и Git repository.

## Сборка

```bash
./gradlew buildPlugin
```

Если wrapper ещё не создан:

```bash
gradle wrapper --gradle-version 9.0.0
./gradlew buildPlugin
```

Архив плагина появится в `build/distributions/`. Установка: **Settings → Plugins → ⚙ → Install Plugin from Disk**.

Для разработки:

```bash
./gradlew runIde
./gradlew test
./gradlew verifyPlugin
```

## Использование

1. Откройте Tool Window **Repo Scope Search** снизу.
2. Укажите адрес GitLab, например `https://gitlab.company.ru`.
3. Нажмите **Создать токен**, завершите создание в браузере и вставьте токен.
4. Нажмите **Проверить** — плагин покажет аккаунт и число доступных непустых репозиториев.
5. Введите текст или regexp, выберите опции и нажмите **Искать**.
6. Результаты добавляются немедленно. Двойной щелчок открывает файл в найденном коммите.

## Семантика режимов

- **Текст**: запрос экранируется и ищется буквально; при выключенном регистре используется Unicode case-insensitive matching Kotlin/JVM.
- **Regexp**: Kotlin `Regex`; многострочная опция включает `MULTILINE` и `DOT_MATCHES_ALL`, поэтому `^`/`$` работают по строкам, а точка может переходить через `\n`.
- **Неточный**: работает только в текстовом режиме. Сравнивает запрос с окном в 1–3 строки около ожидаемой длины; пробелы нормализуются. Порог по умолчанию — 0.82.

## Ограничения первой версии

- Надёжность достигается полным чтением деревьев Git; первый поиск по большому числу репозиториев может скачать значительный объём истории и занять много места. Последующие `fetch` инкрементальные.
- Один и тот же blob может читаться повторно, если присутствует во многих ветках. Возможная следующая оптимизация — кэш совпадений по `(blob SHA, search fingerprint)`.
- LFS pointer-файл ищется как обычный текст; содержимое Git LFS не скачивается.
- Ссылка «файл в основной ветке» не гарантирует, что файл там существует; она намеренно ведёт на текущий путь в default branch.
- Архивные и пустые проекты исключены. Это можно сделать отдельной настройкой.

## Архитектура

- `api/GitLabApiClient.kt` — API пользователя, проектов и пагинация.
- `git/RepositoryCache.kt` — bare-кэш и ветки.
- `git/GitCommandRunner.kt` — cancellable Git subprocess и `GIT_ASKPASS`.
- `search/SearchEngine.kt` — приоритеты, два прохода, поток событий.
- `search/ContentMatcher.kt` — literal/regexp/fuzzy и контекст.
- `ui/RepoSearchPanel.kt` — Tool Window и streaming UI.
