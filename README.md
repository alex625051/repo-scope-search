# Repo Scope Search 0.2.3

Плагин PyCharm для потокового поиска по всем GitLab-проектам, доступным токену.

## Как работает локальный режим

1. `GET /projects` получает доступные проекты и сортирует их по приоритету доступа.
2. Для каждого проекта создаётся bare-кэш `<id>.git` без working tree.
3. Выполняется shallow fetch (`--depth=1`) вершин веток. `--filter=blob:limit=N` просит сервер не передавать крупные blobs. Учти: это сетевой фильтр, а не защита от чтения; подходящий отсутствующий blob Git может запросить по требованию. Плагин заранее отбрасывает файлы больше лимита по размеру из дерева.
4. Для обычного текста/однострочного regexp сначала запускается `git grep -l`, после чего Kotlin читает только файлы-кандидаты для контекста.
5. Multiline и fuzzy требуют полного просмотра подходящих файлов ветки.
6. Файл обрабатывается по одному: его bytes и декодированная строка живут в памяти до окончания анализа файла, а не весь репозиторий целиком.
7. Следующие поиски выполняют fetch только обновлений; кэш сохраняется между перезапусками.

## Серверный режим

Использует `GET /projects/:id/search?scope=blobs`. Репозитории не клонируются. Доступность зависит от редакции GitLab, включённого Exact Code Search/Advanced Search и индекса. Fuzzy не поддерживается. У API нет гарантированной поддержки произвольной ветки: на некоторых установках `ref` игнорируется и поиск фактически выполняется только по основной индексируемой ветке. Поэтому режим «все ветки» является best effort и дедуплицирует повторы.

## Маска файла

Поле `Regex пути` применяется ко всему пути в репозитории. Примеры:

- `(?i)\\.(kt|java)$`
- `^src/main/.*\\.py$`
- `(^|/)Dockerfile$`
- `(?i)\\.(yml|yaml|json)$`

## Ресурсы

- Место: сумма shallow Git object databases; зависит от количества уникальных blobs в вершинах веток и лимита файла.
- Интернет: первый локальный поиск самый тяжёлый, затем передаются изменения; серверный режим передаёт только JSON-результаты.
- Память: до `parallelism × maxFileMb` для контента плюс процессы Git и служебные структуры.
- CPU/диск: fuzzy и multiline самые дорогие; маска пути и default-only резко сокращают объём.

Рекомендуемый старт для 450 проектов: default-only, маска расширений, 4 потока, лимит 2–5 МБ. Сначала попробуйте server; если API недоступен или полнота критична — local.
